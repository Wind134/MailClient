# 1.0.15.0

## 新增：检查更新

- 应用会通过 GitHub Releases 检查新版本：启动后约 30 秒检查一次，之后每 6 小时一次；离线、限流、仓库暂无发布等情况只记日志，不打扰。
- 「设置 → 常规 → 更新」：「自动检查更新」开关（默认开启）、「检查更新」按钮（显示当前版本与结果）。
- 发现新版本时弹出对话框，显示版本号和更新说明，可选「立即更新」「稍后提醒」「跳过此版本」。主窗口在托盘里时改为发一条通知，点击后查看。
- exe 安装版：下载安装程序（带进度，可取消），核对 `SHA256SUMS.txt`，不一致就拒绝；然后静默安装并自动重启，数据不受影响。MSIX 版和绿色版会打开发布页。

文档：[updates.md](updates.md)。仓库地址的配置位置见 [installer.md](installer.md)。
