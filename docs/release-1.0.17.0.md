# 1.0.17.0

## 新增：登录失效提醒与重新登录

- 同步、收信或打开邮件时如果发现账号登录已失效（如 Gmail / Outlook 授权过期、IMAP 密码已修改），会弹窗提示「登录已失效」，可以直接「重新登录」或「稍后」。同一个账号只提醒一次，网络波动不会触发。
- 登录失效的账号在左侧栏显示红色标记，并暂停后台重试，避免反复连接失败。
- 账号右键菜单新增「重新登录」：先检查连接；连接正常时提示无需重新登录，网络有问题时给出说明，确实失效时按账号类型重新登录（Gmail 浏览器授权、Outlook 微软登录、IMAP 输入密码）。必须登录同一个邮箱，登录成功后立即同步，本地邮件不会被删除。
- 启动时会检查每个账号的连接。
