MailClient

MailClient is a free, open-source Windows desktop email client. It lets you read, search, write and send your own email from Gmail, Outlook and IMAP accounts on your own PC.

MailClient 是一款免费、开源的 Windows 桌面邮件客户端。您可以在自己的电脑上阅读、搜索、撰写并发送来自 Gmail、Outlook 和 IMAP 账号的邮件。

This website is public documentation. It does not require a login, does not have user accounts, and does not collect mail. MailClient runs only as a desktop app on your Windows PC.

本网站是公开说明页，无需登录，没有用户账号，也不会收集邮件。MailClient 只作为桌面应用在您的 Windows 电脑上运行。

What MailClient is / 这是什么

MailClient is a personal, open-source WinUI 3 application for Windows 10 and Windows 11. You add one or more of your own mail accounts, and the app talks directly to those providers from your computer. Mail, account settings, and credentials stay in a local SQLite database and encrypted credential file under %LocalAppData%\MailClient.

The project supports:

  • Gmail, using Google OAuth 2.0 (installed / desktop app flow with PKCE) and then IMAP/SMTP over XOAUTH2
  • Outlook / Microsoft 365, using Microsoft Graph and MSAL
  • QQ, 163/126, and other IMAP/SMTP servers

We do not operate a backend that receives, stores, or analyzes your mail, and we do not offer a cloud service that would require you to upload mailbox data to the developer. The app includes no telemetry, analytics, or advertising. Optional update checks query only the public GitHub Releases API and do not send your email address or tokens.

MailClient is maintained by GitHub user Wind134. The source code is at github.com/Wind134/MailClient. On Windows the Start Menu shortcut may appear as 「邮件」, but the product name is MailClient.

MailClient 是个人维护的开源 WinUI 3 应用，适用于 Windows 10 / 11。您在本机添加自己的邮箱账号后，应用会从这台电脑直接连接相应的邮件服务商。邮件、账号设置和凭据保存在 %LocalAppData%\MailClient 下的本地 SQLite 数据库和加密凭据文件中。我们不运营接收或分析邮件的后端，也没有遥测。项目由 GitHub 用户 Wind134 维护。

How MailClient uses Google data / Google 用户数据的用途

If you choose to add a Gmail account in the desktop app, MailClient requests only the following Google OAuth scopes:

ScopeWhy it is requested
https://mail.google.com/ Restricted mail scope. Used only to connect to Gmail IMAP (imap.gmail.com:993) and SMTP (smtp.gmail.com:465) with XOAUTH2, so you can sync, display, search, organize, and send your own email on your device.
openid OpenID Connect, so the authorization flow can authenticate the Google account and confirm which account you authorized.
email (https://www.googleapis.com/auth/userinfo.email) Read the account email address so the app can display the correct account and use it as the IMAP/SMTP username.
profile (https://www.googleapis.com/auth/userinfo.profile) Read basic profile information such as the account name, to label the account in the app.

With those scopes, the app may access your email address and basic profile, email messages, headers, attachments, folders and labels, and addresses that already appear in message headers. OAuth access and refresh tokens are stored only on your PC (Windows DPAPI). Google user data stays on your device and is transmitted only directly between your PC and Google. The developer never receives this data.

MailClient does not request Google Drive, Calendar, People/Contacts, or other unrelated scopes. It does not download your address book through a contacts API.

如果您在桌面应用中添加 Gmail 账号，MailClient 只会申请上述 Google OAuth 范围：用 https://mail.google.com/ 通过 XOAUTH2 连接 Gmail IMAP/SMTP，以便在本机同步、展示、搜索、整理和发送您自己的邮件；用 openid、email、profile 识别并显示该 Google 账号。数据留在您的设备上，只在您的电脑与 Google 之间直接传输，开发者不会收到这些数据。

MailClient does not use artificial intelligence or machine learning on Google user data, does not generate images, and does not use Google APIs to create or distribute AI-generated non-consensual intimate imagery (AI NCII).

The app complies with the Google APIs Terms of Service and the Google API Services User Data Policy, including Limited Use.

MailClient's use and transfer of information received from Google APIs to any other app will adhere to Google API Services User Data Policy, including the Limited Use requirements.

MailClient 不会对 Google 用户数据使用人工智能或机器学习，不会生成图像，也不会使用 Google API 创建或传播人工智能生成的非自愿亲密影像（AI NCII）。完整说明见 Privacy Policy / 隐私权政策。

Privacy and data / 隐私与数据

  • MailClient does not collect, upload, or sell your personal data. There is no telemetry, analytics, or advertising identifier.
  • The app connects only to the mail providers you configure, and optionally to GitHub for update checks.
  • Credentials are encrypted with Windows DPAPI for the current Windows user. Transport to providers uses HTTPS/TLS.
  • You can remove an account in the app, uninstall and delete %LocalAppData%\MailClient, and revoke access at Google Account permissions.

The full policy — including the data the app accesses, how each category is used, storage, sharing, retention, and contact information — is here: MailClient Privacy Policy / 隐私权政策.
