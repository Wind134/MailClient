MailClient

一款在您自己的 Windows 电脑上运行的本地桌面邮件客户端。邮件、账号与登录凭据保存在本机，不经过开发者服务器。

A local Windows desktop email client. Your mail stays on your PC — open source, no developer backend, no telemetry.

这是什么

What it is

MailClient 是个人维护的开源 WinUI 3 邮件客户端（Windows 上显示名称可为「邮件」）。它直接连接您登录的邮件服务商，在本机用 SQLite 缓存邮件与账号数据。

我们不运营用于接收、存储或分析您邮件内容的后端服务器，也不提供要求您把邮箱数据上传给我们的云同步服务。

项目由 GitHub 用户 Wind134 维护，源代码位于 github.com/Wind134/MailClient。

主要功能

Features

本地存储 账号、邮件缓存与草稿保存在本机 %LocalAppData%\MailClient（SQLite）。
多账号 支持 Gmail（OAuth）、Outlook / Microsoft 365（MSAL / Graph）、QQ / 163 / 126 与通用 IMAP/SMTP。
凭据保护 登录令牌与密码使用 Windows DPAPI（当前用户范围）加密保存。
更新检查 可选：仅请求 GitHub Releases 公开接口，不附带邮箱地址或令牌。

隐私与数据

Privacy & data

  • 不收集、不上报、不出售您的个人数据；应用没有遥测、分析或广告标识。
  • 应用只会为完成您配置的邮件功能，直接连接 Google、Microsoft 或您设置的 IMAP/SMTP 服务器。
  • 若使用 Google 账号登录，Google 用户数据仅用于在您的设备上收发与管理您自己的邮件，并遵守 Google API Services User Data Policy（含 Limited Use）。

完整说明见：MailClient 隐私权政策。
