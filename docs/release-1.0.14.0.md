# 1.0.14.0

## 改为 exe 安装程序

- 不再以自签名 MSIX 作为发布方式，改为**图形 exe 安装程序**：`MailClient-Setup-1.0.14.exe`（简体中文，Fluent 风格，Mica 背景，随系统浅色/深色，动画进度），以及绿色版 `MailClient-1.0.14-win-x64-portable.zip`。
- 每用户安装到 `%LocalAppData%\Programs\MailClient`，**不需要管理员权限**；可更改安装位置、可选桌面快捷方式；在「已安装的应用」里有卸载入口。
- 升级：直接运行新版安装程序，会先关闭正在运行的「邮件」，数据与设置不受影响。
- 卸载界面同样风格，「同时删除我的邮件数据和设置」默认**不勾选**。
- 应用改为自包含免打包运行：通知、托盘、单实例、图标与 MSIX 版一致；数据位置不变（`%LocalAppData%\MailClient`）。

## 安装提示

安装包尚未做代码签名，首次运行 SmartScreen 会提示：点 **「更多信息」→「仍要运行」**。

## 注意

- 已安装 MSIX 版（1.0.13.0 及以前）的用户：两者可以并存，但不要同时运行（单实例不跨两种形态，会同时读写同一份数据）。确认 exe 版可用后可卸载 MSIX 版。
